# Шорткаты tmux

Справка по горячим клавишам, которые задаёт эта конфигурация
(`tmux.conf` + `tmux.reset.conf` + подключённые плагины).
Всё ниже, кроме отдельно помеченного, нажимается **после префикса**.

Активные бинды в `tmux.reset.conf` — стандартные из
[oh-my-tmux](https://github.com/gpakosz/.tmux), адаптированные под пути этого
репозитория. Прежний, нестандартный screen-style набор оставлен в том же
файле закомментированным (на случай, если захочется вернуть).

## Префикс

- **Ctrl-b** — единственный префикс (стандартный tmux-префикс).

## Окна и сессии

| Клавиша | Действие |
|---|---|
| `Ctrl-c` | новая сессия |
| `Ctrl-f` | найти и переключиться на сессию по имени |
| `BTab` | переключиться на последнюю активную сессию |
| `Ctrl-h` / `Ctrl-l` (можно держать) | предыдущее / следующее окно |
| `Ctrl-Shift-h` / `Ctrl-Shift-l` | поменять текущее окно местами с предыдущим / следующим |
| `Tab` | последнее активное окно |
| `r` | перечитать конфиг (`source-file ~/.config/tmux/tmux.conf`) |
| `e` | открыть `tmux.conf` в `$EDITOR` новым окном и применить после сохранения |

## Панели (pane)

| Клавиша | Действие |
|---|---|
| `-` | разбить панель по горизонтали (сверху/снизу) |
| `_` | разбить панель по вертикали (бок о бок) |
| `h` / `j` / `k` / `l` (можно держать) | перейти в панель слева / снизу / сверху / справа (vim-стиль) |
| `H` / `J` / `K` / `L` (можно держать) | изменить размер панели влево / вниз / вверх / вправо на 2 |
| `>` / `<` | поменять местами со следующей / предыдущей панелью |
| `Ctrl-l` | очистить экран и историю панели |

Дефолтные tmux-бинды (не переопределены этим конфигом, работают как обычно):
`z` — zoom панели, `%`/`"` — сплиты по умолчанию, `,` — переименовать окно,
`&` — закрыть окно с подтверждением, `x` — закрыть панель с подтверждением,
`s`/`w` — выбрать сессию/окно из дерева (choose-tree).

## Копирование и буферы

- Режим копирования — **vi** (`mode-keys vi`), заходить `prefix [` или `Enter`.
- В режиме копирования (`copy-mode-vi`): `v` — начать выделение, `Ctrl-v` —
  прямоугольное выделение, `y` — скопировать и выйти, `Escape` — отмена,
  `H`/`L` — начало/конец строки.
- `set-clipboard on` — выделенный текст сам уходит в системный буфер обмена.
- `b` — список буферов, `]` — вставить буфер (paste-buffer), `=` — выбрать
  буфер из списка (choose-buffer). Оригинальные oh-my-tmux клавиши `p`/`P`
  заняты плагином tmux-floax (см. ниже), поэтому здесь вместо них — стоковые
  клавиши vanilla tmux.

## Плагины

Управляются через **tpm** (`tmux-plugins/tpm`), список — в `tmux.conf`.

| Клавиша | Плагин | Действие |
|---|---|---|
| `p` | omerxx/tmux-floax | открыть плавающую панель (80%×80%, путь наследуется) |
| `o` | omerxx/tmux-sessionx | fzf-переключатель сессий/путей (zoxide включён) |
| `Ctrl-y` (внутри sessionx) | tmux-sessionx | открыть новое окно по выбранному пути |
| `F` | sainnhe/tmux-fzf | общее fzf-меню управления tmux (сессии/окна/панели) *(дефолт плагина)* |
| `u` | wfxr/tmux-fzf-url | найти и открыть URL, видимый в панели, через fzf *(дефолт плагина)* |
| `Space` | fcsonline/tmux-thumbs | быстрый выбор/копирование строк с экрана (пути, хэши, URL и т.п.) *(дефолт плагина)* |
| `y` (и `Enter`/выделение мышью) | tmux-plugins/tmux-yank | копирование в системный буфер обмена *(дефолт плагина)* |
| `Ctrl-s` | tmux-plugins/tmux-resurrect | сохранить состояние сессий |
| `Ctrl-r` | tmux-plugins/tmux-resurrect | восстановить состояние сессий |

`tmux-continuum` дополнительных клавиш не добавляет — автосохранение работает в
фоне, а восстановление последней сессии происходит автоматически при запуске
tmux (`@continuum-restore 'on'`).

### Управление самими плагинами (tpm, дефолтные биндинги)

| Клавиша | Действие |
|---|---|
| `I` | установить плагины из списка |
| `U` | обновить все плагины |
| `Alt-u` | удалить плагины, убранные из списка |
